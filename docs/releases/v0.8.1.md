# sharecli v0.8.1

Build-and-release-hygiene release. This is the first release since `v0.3.0` (2026-07-04).

> **Release status:** `0.8.0` was recorded in-repo but was **never tagged or released**. `0.8.1` supersedes that unreleased version line. The earlier `1.0.0` bump was likewise recorded in-repo only and never tagged or published, so published history remains `v0.3.0` followed by `v0.8.1`.

## Headline changes

- **Dead dependency removal.** Dropped unreachable `PhenoInfra` pins.
- **CI honesty.** Removed failure-masking constructs so CI results reflect actual failures.
- **FFI Windows build gate.** Allowed the workspace to build on Windows without the unix-only test target.
- **FFI dylib discovery.** Integration tests locate the freshly built `libsharecli_ffi` dylib through generated debug/release paths.
- **E2E test repair.** Repaired the `e2e_serve_healthz` suite so it runs against the current server surface.
- **Resilience test repair.** Repaired resilience tests so they run as intended.
- **Dependabot batches.** Landed accumulated dependency bumps (`jsdom`, `playwright`, and related).
- **VERSION hygiene.** `VERSION` now contains exactly `0.8.1` followed by a newline.

## Known limitations

- **G0:** Being fixed. Test results previously did not gate.
- **G1:** Split process pools.
- **G2:** Admission does not cover process lifetime.
- **G5/G6:** Cache identity and artifact restoration are incomplete.
- **G8:** No Windows Job Object or Linux cgroup enforcement.

`0.8.1` is a build-and-release-hygiene release, not a correctness-complete one.
